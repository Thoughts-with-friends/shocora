Console file system

The Wii U's tree as IOSU names it:
/vol: the title's volumes (code, content, meta, save, add-on content), also at their place in system memory under /vol/storage_mlc01/usr;
/dev: IOSU's devices and their open handles;
/proc: the emulator's VFS mount table, IOSU handles, open files and folders.
Open a file in the explorer. Text is shown with line numbers, anything else as a hex dump.
